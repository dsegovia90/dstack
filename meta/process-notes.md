# Process notes — cross-project signal

This file collects **human-curated** excerpts from `/dstack-retro` runs across every project,
in every repo, that has ever run dstack — not auto-merged, pasted in deliberately once a
pattern shows up more than once. A single retro's "process observations" section is one data
point; this file is where recurring signal across multiple data points accumulates into
something worth actually changing `spec/llm-coding-workflow.md` over.

When pasting an excerpt in, include: which project/repo it came from, the date, and the
observation itself. When the same shape of observation shows up a second or third time from a
different project, that's the trigger to actually edit the spec — note here when that happens
and what changed, so this file also doubles as a lightweight changelog of *why* the spec looks
the way it does.

Starts empty. Nothing has been pasted in yet — this repo (and its `examples/reference-project/`
retro) are the first source once real projects start running dstack v2 and generating retros
of their own.
